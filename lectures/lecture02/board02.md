## Фрейм 3. Критерии (12 мин)

**Заранее:** `04_tangent.png`, `05_hessian_map.png`.

**Живьём.** Та же чаша, касательная в точке: «график над касательной — критерий первого порядка». Формула $f(y) \ge f(x) + \nabla f(x)^\top(y - x)$ крупно, обвести: «линейная модель — глобальная нижняя оценка; из этого вырастет условие оптимальности во фрейме 6». Показать `04`.

Ниже: «$C^2$: $\nabla^2 f(x) \succeq 0$ всюду». Пример у доски — квадратичная: $\nabla^2 f = Q$, «выпукла $\iff$ собственные числа $Q \ge 0$». Второй пример — $(x^2 - 1)^2$: $f'' = 12x^2 - 4$, «отрицательна при $|x| < 1/\sqrt3$» — одной точки достаточно. Показать `05` — «то же самое кодом».

Демо (a), 3 минуты: тест хорды и карта гессиана для трёх функций; сюрприз с $f_2 = e^{x_1} + x_2^2 + x_1x_2$ (перекрёстный член). Фраза: «тесты умеют искать контрпример, доказывать — не умеют».

Доказательства критериев не разбираем — «свёрнуто в конспекте».

## Фрейм 4. Операции (8 мин)

**Заранее:** `06_max_affine.png`, `07_sublevel.png`.

**Живьём.** Столбиком четыре операции, у каждой — пример:

1. $\alpha f + \beta g$, $\alpha, \beta \ge 0$ → $\Vert Ax - b\Vert^2 + \lambda\Vert x\Vert_1$;
2. $f(Ax + b)$ → любая норма от аффинного;
3. $\max_i f_i$ → показать `06`: «излом, но выпукла»; $\max_i |a_i^\top x - b_i|$ из ДЗ 1;
4. $g \circ f$, $g$ выпукла и **не убывает** → $e^{f}$; контрпример $(x^2-1)^2$: внешняя $u^2$ не монотонна.

Внизу — подуровневое множество: штрихую $\{f \le c\}$ под горизонтальной линией на чаше — «выпукло». Показать `07`: у двугорбой распалось на два куска. Стрелка к фрейму 5: «неравенство $h_i \ge 0$ с вогнутой $h_i$ задаёт выпуклое множество — вот зачем это нужно».

## Фрейм 5. Выпуклые задачи (13 мин) — главный фрейм

**Заранее:** `08_local_global_proof.png`.

**Живьём, часть 1 — стандартная форма** (4 мин). Записать (NLP) из лекции 1 и рядом три условия: $f$ выпукла; $g$ **аффинны**; $h_i$ **вогнуты**. Вопрос в зал: «почему равенства только аффинные?» — нарисовать окружность. Вопрос: «$\Vert x\Vert^2 \le 1$ — можно? а $\Vert x\Vert^2 \ge 1$?» — второе задаёт внешность шара.

**Живьём, часть 2 — теорема** (9 мин). Формулировка крупно: «локальный минимум выпуклой задачи — глобальный». Доказательство рисую по шагам, повторяя `08`: капля $\Omega$, точка $x^\ast$, окрестность-кружок, произвольная точка $y$, отрезок к ней (внутри — выпуклость $\Omega$), точка $\tilde x$ на отрезке внутри кружка. Две строки:

$$f(x^\ast) \le f(\tilde x) \le (1-t)f(x^\ast) + tf(y) \;\Rightarrow\; f(y) \ge f(x^\ast).$$

Подписать над первым неравенством «локальный минимум», над вторым «выпуклость $f$». Фраза: «убери любое из двух — и появятся ямы, как в примере 7.4».

Следствия одной строкой: множество решений выпукло; строго выпукла → решение одно.

## Фрейм 6. Условие оптимальности (12 мин)

**Заранее:** `09_optimality.png` спрятана, `10_projection.png` видна.

**Живьём.** Многоугольник $\Omega$, концентрические линии уровня с центром снаружи, точка $x^\ast$ на ребре. Стрелка $-\nabla f$ из $x^\ast$ наружу; веер стрелок $y - x^\ast$ внутрь. «Угол между антиградиентом и любым направлением внутрь — не острый: некуда идти». Формула:

$$\nabla f(x^\ast)^\top (y - x^\ast) \ge 0 \quad \forall y \in \Omega.$$

Доказательство «$\Leftarrow$» — одна строка из критерия первого порядка (стрелка к фрейму 3). Раскрыть `09`. Второй случай: центр линий уровня внутри $\Omega$ → веер во все стороны → $\nabla f = 0$.

Пример: квадратичная, $x^\ast = -B^{-1}c$, значение $-\tfrac12 c^\top B^{-1} c$ — «запомните, встретится в Ньютоне».

Проекция (3 мин): показать `10`; на шар — $p/\Vert p\Vert$, на параллелепипед — `clip`. Демо (c): проверка условия на 1000 случайных $y$ — «условие можно *проверить*, не зная ответа».

## Запасные вопросы в зал

- «Выпукла ли функция $x_1 x_2$? А множество $\{x_1 x_2 \ge 1, x > 0\}$?» (нет / да — упражнение 12.1в).
- «Может ли у выпуклой задачи быть два разных решения?» (да, если $f$ не строго выпукла: LP с целью параллельно ребру).
- «$\nabla f(x^\ast) \ne 0$ в решении — метод сломался?» (нет, решение на границе).
- «Композиция двух выпуклых — выпукла?» (не всегда: $(x^2 - 1)^2$).
